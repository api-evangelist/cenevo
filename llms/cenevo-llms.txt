# Cenevo (Labguru)

> Cenevo is an AI-enabled lab automation company (maker of Labguru and Mosaic, formerly BioData) that helps scientists, research institutions, and biopharmas connect and automate the laboratory. The Labguru API is a JSON / REST API providing create, read, update, and delete access to almost all data in Labguru — antibodies, cell lines, compounds, plasmids, experiments, inventory, storage, equipment, datasets, and webhook subscriptions — using token-based authentication.

## APIs

- [Labguru API v1](https://my.labguru.com/api-docs/index.html): JSON/REST API, 74+ resource families, base https://my.labguru.com/api/v1
- [Labguru API v2](https://my.labguru.com/api-docs/index.html): newer surface (projects, experiments, reports, equipment), base https://my.labguru.com/api/v2

## Authentication

- Session-token model: POST https://my.labguru.com/api/v1/sessions with login + password (+ optional account_id) returns a token.
- The token is passed as the required `token` query parameter on every request. SSO customers generate a personal token from account settings.
